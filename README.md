We were prompted to create a solution to solve the issue that Relationship Managers (RMs) Face: Getting the right information to the right client at the right time

# Rendez-vous

**This Week in a Changing World:** a weekly brief that helps relationship managers know which client to call, about what, and why now.

🔗 **Live demo:** (https://bnp-case-comp-demo.vercel.app/)

## Run it Locally
git clone [https://github.com/rosellaliu079/rendez-vous.git](https://github.com/rosellaliu079/BNP-Case-Comp-Demo.git)
cd rendez-vous
npm install
npm run dev

## What it does
Rendez-vous sits inside the tools RMs already use (Outlook and the CRM) and delivers 3-5 items a week, built from two workflows:

- **Market-triggered:** links a market, industry or regulatory development to a specific client's context and the bank's relationship with them.
- **Déjà Due:** surfaces follow-ups and follow-on deals at the right time, based on rules the RM sets.

Every item links to its sources. Nothing reaches a client without the RM reviewing it.
